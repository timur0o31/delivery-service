# Система управления доставкой

Учебный backend-проект для работы с заказами, клиентами и курьерами. Приложение предоставляет HTTP API и передаёт задачи по назначению курьеров отдельному обработчику через брокер сообщений.

## Возможности

- Регистрация клиентов и курьеров, аутентификация и разграничение доступа по ролям.
- Создание, отмена и просмотр заказов, обновление статуса доставки.
- Обработка заявок курьеров и управление их сменами.
- Асинхронная обработка назначения курьера и истечения времени назначения.
- Интеграция с Bitrix24 через ресурсный адаптер Jakarta EE.

## Технологии

Java 17, Spring Boot, Spring Security, Spring Data JPA, Hibernate, PostgreSQL, ActiveMQ, STOMP, JMS, Jakarta EE, Maven, Docker Compose.

## Устройство проекта

- `blps-main` — HTTP API, бизнес-логика и публикация задач через STOMP.
- `blps-worker` — обработчик сообщений из очереди JMS.
- `blps-domain` — общие сущности, репозитории и модель сообщений.
- `bitrix24` — ресурсный адаптер для интеграции с внешней системой.

## Сборка и запуск

Для сборки нужны JDK 17 и Maven:

```bash
./mvnw clean package
```

Приложение и worker собираются как WAR и рассчитаны на развёртывание в сервере приложений WildFly. В настройках указан источник данных JNDI `java:/PostgresDS`. Также для работы используются PostgreSQL, ActiveMQ и ресурсный адаптер `bitrix24`. Имеющийся `docker-compose.yml` описывает только PostgreSQL; полной автоматизированной конфигурации запуска в репозитории пока нет.

Перед запуском необходимо настроить сервер приложений, источник данных, брокер и параметры интеграций для своего окружения. Инструкция будет дополнена после проверки полного запуска.
